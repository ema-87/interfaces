# Entregable: Interfaces 2025 - Entregable 2

Páginas incluidas:
- `index.html` — portada con botones "Ir a Login" e "Ir a Home" y la lista de integrantes.
- `login.html` — página de ejemplo para login.
- `home.html` — página de ejemplo para home.
- `styles.css` — estilos para que la página luzca como la imagen solicitada.

Cómo publicar en GitHub Pages (opción rápida):
1. Copia los archivos al repositorio (raíz del repo).
2. Push a la rama `main` (o la rama principal que uses).
3. En GitHub: Settings → Pages → Source → seleccionar "main" branch y carpeta "/ (root)". Guardar.
4. Después de unos segundos/minutos la URL será:
   `https://ema-87.github.io/interfaces/`
   (si tu repo se llama `interfaces` y tu usuario es `ema-87`)

Comandos git mínimos:
```
git add index.html styles.css login.html home.html README.md
git commit -m "Agregar páginas para entregable 2 y estilos"
git push origin main
```

Si prefieres que lo publique en `gh-pages` o en la carpeta `docs/`, dímelo y ajusto las instrucciones.
